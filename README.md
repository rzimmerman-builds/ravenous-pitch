# Ravenous Pitch

Responsive static microsite for the RAVEnous pitch.

## Preview locally

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

1. Create a new GitHub repository and add everything in this folder.
2. In Vercel, choose **Add New → Project** and import the repo.
3. Framework preset: **Other**.
4. No build command is required.
5. Output directory can remain blank/default.
6. Deploy.

The same deployment is responsive across desktop and mobile.
